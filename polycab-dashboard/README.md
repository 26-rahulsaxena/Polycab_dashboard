# Polycab India Ltd: financial dashboard

Interactive Streamlit dashboard of Polycab India Ltd (NSE: POLYCAB): financial statements FY18–FY26 and the
latest quarters, ratios, segments, KPIs, expansions, peers, ownership and the share price.

Run locally:

```
pip install -r requirements.txt
streamlit run app.py
```

Data: Polycab annual reports and investor presentations (where verified; each figure cites its page), company
results, and daily prices from yfinance (the "Refresh prices" button in the sidebar fetches the latest).
Independent student project for education only. Not affiliated with or endorsed by Polycab India Ltd.
Not investment advice.
